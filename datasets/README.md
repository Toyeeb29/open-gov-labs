# Datasets

Simulated workplace artifacts that labs and companies share:

- vendor questionnaires
- SOC report excerpts (original fiction)
- access review exports
- tickets
- logs
- AI intake forms
- contracts / DPA excerpts (original fiction)

If a file is company-specific, prefer `companies/<name>/...`. Use this folder for reusable fixtures, generators, and shared packs.

Current fixtures: `evidence-fixtures/`, `iac-fixtures/`, `github-fixtures/`.

All people, vendors, and records are fictional. No real customer, patient, or employee data.
