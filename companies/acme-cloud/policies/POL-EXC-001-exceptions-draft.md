# Policy Exception Procedure (DRAFT — not approved)

Owner: CISO  
Status: Draft since March 2026  
Last editor: Priya Shah

Intended steps (not in force):

1. Requester writes the policy clause, duration (90 days max), compensating controls, and residual risk.
2. Manager + control owner + Security & Compliance review.
3. High residual exceptions also need CISO.
4. GRC logs the exception. Access or config is not changed until the log exists.
5. Expiry generates a ticket. Open-ended exceptions are rejected.

There is **no approved exception procedure** as of 21 September 2026. POL-ACCESS-001 still requires a "logged policy exception" for MFA deviations.
