## How to use this folder

Open these files the way you would open a company intranet. Labs tell you the assignment. They do not list every finding.

```
org/           people and reporting lines
policies/      approved and draft policies
controls/      control records (often incomplete)
risks/         risk register excerpts
assets/        systems in scope
vendors/       third parties
contracts/     security and privacy terms
evidence/      what control owners already uploaded
audits/        PBC lists and auditor notes
tickets/       Jira-style work
ai-systems/    AI inventory and intakes
security/      operational security notes
privacy/       privacy records
```

All people, vendors, and records are fictional.

All current labs use this company. Start at [tickets/work-queue.md](tickets/work-queue.md). Practice GRC first.
