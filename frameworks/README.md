# Frameworks

Machine-readable framework metadata. The product must not hard-code a United States-only control catalog.

Each framework file should include:

- stable id
- name
- publisher
- jurisdiction or region (when applicable)
- authoritative source URL
- version / publication year
- notes on what this repo will and will not reproduce

Do not paste copyrighted control text in bulk. Map to control identifiers and cite the publisher. Lab files reference framework ids from here.

See [docs/framework-schema.md](../docs/framework-schema.md).
